# Repositório Memyts

Este repositório contém o código do **Memyts** e suas diferentes versões, cada uma desenvolvida para atender a uma **plataforma de venda específica**.
Nosso objetivo é garantir que cada plataforma tenha uma **experiência otimizada**, adaptada aos seus **requisitos e gateways de pagamento**.

---

## 🗂️ Estrutura das Branches

Para manter a organização e facilitar o desenvolvimento e o deploy, adotamos a seguinte estrutura de branches:

- **`main`**
  Contém o código específico para a **Plataforma de Vendas 1 (Cartpanda)**.
  É responsável pelo conteúdo que será exibido em **[memyts.com](https://memyts.com)**.

- **`hml`**
  Contém o código específico para a **Página de Homologação**.
  É responsável pelo conteúdo que será exibido em **[hml.memyts.com](https://hml.memyts.com)**.
